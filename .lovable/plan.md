Existing `buses`, `bus_routes`, `student_bus_assignments`, `bus_fee_payments` tables get extended; new tables added for drivers, trips, GPS pings, notifications, and Paystack payments. Split into 3 stages so each turn ends with a working app.

- **DB migration**: extend `buses` (registration_no, vehicle_type, color, assistant, gps_enabled, insurance_expiry, inspection_date, status enum active/maintenance/out_of_service, assigned_driver_id). - Maps: Google Maps connector (browser key for JS API; gateway for Distance Matrix).

- Isolation: every table has `school_id`; RLS via existing `is_school_admin`, plus new helpers `is_driver_of_trip`, `parent_can_see_trip`.
